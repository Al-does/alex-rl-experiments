How to read this study

Each point is a three-coordinate block of the six-state belief, wnηn. Its coordinate sum is the posterior probability of that component. The triangular plane has vertices (w,0,0), (0,w,0), (0,0,w); it shrinks toward the origin as w approaches zero. Sweeping w from zero to one fills a tetrahedral envelope. The pair of blocks lives in a 5-simplex.

Sequence mode shows a growing trajectory, a large point at the current position, and the current weighted plane. Probe planes use the raw decoded component mass, which may be negative or exceed one. Predictions are never clipped or renormalized. All four plots use identical axes, expanded to include plotted predictions.

Both checkpoints see the same final-policy greedy histories. Initialization is an off-policy representation control, not an initialization-policy rollout. Independent complete episodes form the fit and held-out sets. Post-final RMSNorm is the primary representation, fixed before evaluation; all four pre-normalization residual streams are available as robustness comparisons. Affine probes use training-only whole-episode cross-validation. R² and out-of-simplex rates use all held-out positions, not just the displayed sample.

The filter conditions on visible delayed tokens and executed actions, never reward or latent state. At position 0 the input is BOS; positions 1–127 reveal delayed tokens. Position 127 is the terminal observation, so the 128-position context contains 127 executed actions. The target is the decision-time arrival belief, after the preceding action transition. This adapts the passive article to the experiment's controlled HMM.

High probe fit measures linear accessibility; it does not establish causal use or uniquely identify internal computations. Predictive, current-observation, initialization, Gaussian-feature and shuffled-label controls, target variance, and episode-bootstrap comparisons are in the full reports. One training seed per run limits generalization across trained models.

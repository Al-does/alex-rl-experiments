# Cassandra belief factoring: seed-42 5M comparison

## Scope

This report compares the two completed 5M-step PPO runs:

| condition | action scope | result run | sampled steps |
|---|---|---|---:|
| Global actions | 4 actions | [`ppo/results/20260818T063416Z-bfc0c2df`](../../ppo/results/20260818T063416Z-bfc0c2df/) | 5,015,952 |
| Targeted actions | 10 actions | [`targeted_ppo/results/20260818T193443Z-e37dbc13`](../../targeted_ppo/results/20260818T193443Z-e37dbc13/) | 5,015,952 |

Both runs use seed 42, PPO, the same 96-wide three-layer transformer, a
64-step context, 1,000-step episodes, and discount 0.999. The policy receives
only the current 16-way observation symbol and the previous action one-hot; it
does not receive the Bayesian belief, latent component state, or reward.

The probes use 60,000 fit steps and 80,000 held-out test steps. Every checkpoint
within a condition is evaluated on matched histories generated by a fixed,
checkpoint-independent behavior policy. Global behavior probabilities are
`(operate=.68, inspect=.20, repair=.08, replace=.04)`. Targeted behavior divides
the same aggregate maintenance probability equally across the four components:
each repair has probability `.02` and each replacement `.01`. Consequently,
checkpoint comparisons do not conflate representation changes with each
checkpoint choosing different probe actions.

This is a **single-seed exploratory result**, not an estimate of a population
effect.

## Environment and actions

The hidden state contains four exchangeable components. Each is in one of four
ordered conditions:

```text
broken < bad < fair < good
```

Every episode starts with all components good.

| action | transition / observation | immediate reward |
|---|---|---:|
| `operate` | Independently degrades every non-broken component by one level with probability 0.03; after transition, the product passes only if every component passes, with per-condition pass probabilities `(0, .75, .95, 1)` | Product of per-component expected quality terms `(0, .7275, .9440, .9985)` evaluated on the pre-action conditions |
| `inspect` | Leaves state unchanged and emits one noisy bit per component; positive-bit probabilities for `(broken, bad, fair, good)` are `(.02, .05, .80, .97)` | -1 |
| global `repair` | Independently improves every bad or fair component by one level with probability .8; good and broken components are unchanged | -3 |
| global `replace` | Deterministically restores all four components to good | -15 |
| targeted `repair_component_i` | Applies the same .8 repair transition only to component `i`; all others are unchanged | -.75 |
| targeted `replace_component_i` | Deterministically restores only component `i` to good | -3.75 |

The targeted costs divide the global costs by four, but the targeted controller
must spend separate actions and separate environment steps to service multiple
components. Thus this comparison changes both action cardinality and action
semantics; it does not isolate cardinality alone.

## What an optimal controller should learn

The exact 256-state Bayesian posterior is a sufficient information state for
both POMDPs, but reward optimization does not require a neural network to make
that entire posterior linearly reconstructible. A smaller representation is
enough if it preserves the action values.

For the **global-action** environment, every maintenance action treats component
labels identically. An optimal policy can therefore be permutation-invariant. It
should retain enough joint or aggregate uncertainty to estimate production
quality, the probability of broken components, the value of inspection, and
when global repair or replacement outweighs continued operation. Stable
component identities are not intrinsically necessary.

For the **targeted-action** environment, an optimal policy additionally needs
action-relevant identity: which component is most likely bad or fair (repairable)
and which is likely broken (replaceable). It must combine this labeled
information with aggregate production quality. The original prediction was
therefore that targeted control would preserve more labeled component belief
than global control.

As reward references, finite-horizon dynamic programming on the fully observed
256-state MDP gives privileged 1,000-step oracle upper bounds of **664.12**
(global) and **769.63** (targeted). These are not achievable POMDP scores because
the oracle observes the true component states. An executable QMDP heuristic
that instead receives the exact Bayesian belief obtained from the ordinary
action/observation history achieved:

| scope | mean return over 300 episodes | SE | policy action fractions |
|---|---:|---:|---|
| Global | 573.07 | 2.44 | operate .951, repair .042, replace .007 |
| Targeted | 180.04 | 3.80 | operate .898, repairs .085 total, replacements .017 total |

QMDP is an approximate policy, not the exact POMDP optimum. Its achieved return
is an empirical lower bound on what is attainable with exact belief, while the
fully observed dynamic program is an upper bound.

## What each probe target asks

Each target is computed from the environment's exact Bayesian posterior after
accounting for the full action and observation history.

| target | question answered by a successful affine probe |
|---|---|
| `joint_belief` | Can the representation reconstruct the exact posterior over all `4^4 = 256` joint component states, including dependencies between components? |
| `component_contrast` | Can it reconstruct each named component's four-state marginal? Three independent simplex coordinates per component produce 12 targets. |
| `identity_deviation` | After removing the mean component marginal, can it still identify how each named component differs from the machine-wide average? This is the cleanest identity-specific target. |
| `aggregate_contrast` | Can it reconstruct the mean marginal condition across components, ignoring component identity? |
| `labeled_expected_condition` | Can it predict each named component's expected condition in fixed component order? |
| `sorted_expected_condition` | Can it predict the same expected conditions after sorting them, retaining severity but discarding identity? |
| `next_operate_pass_probability` | Can it predict the posterior probability that the next `operate` action emits a passing-product observation? |
| `expected_action_reward` | Can it predict the posterior expected immediate reward of every available action? In this environment maintenance rewards are state-independent, so most variation comes from `operate`. |
| `broken_count_distribution` | Can it predict the posterior distribution over zero through four broken components without identifying which are broken? |
| `total_correlation` | Can it predict the posterior KL divergence from the joint belief to the product of component marginals, i.e. how strongly the component beliefs are statistically coupled? |

## How to read the reported metrics

| metric | interpretation |
|---|---|
| `r_squared` | Held-out multivariate R². `1` is perfect, `0` matches a global-mean target predictor, and negative values are worse. Higher is better. |
| `mse` | Held-out mean squared error in the target's native coordinates. Lower is better, but values are not comparable across different targets. |
| `target_variance` | Held-out variance used to normalize MSE. |
| `global_mse_ratio` | `mse / target_variance`, equivalently `1 - R²`. Lower is better; `1` matches the global-mean baseline. |
| `observation_only_r_squared` | R² of a separate affine baseline using only the current symbol and previous action. |
| `representation_gain_over_observation_r2` | Transformer R² minus observation-only R². Positive values show information accessible from history through the transformer beyond the current input. |
| `branch_baseline_mse` | Error from predicting a separate target centroid for each current-symbol/previous-action group. |
| `fine_mse_ratio` | Probe MSE divided by branch-baseline MSE. Below `1` means the representation resolves variation within the current-input branch; above `1` does not. |
| `fine_mse_improvement` | Branch-baseline MSE minus probe MSE. Positive is better than that branch baseline. |
| `factor_specific` | Component-by-component R² and errors obtained by splitting the `component_contrast` prediction. |
| `activation_pca.cev90/95/99_dimension` | Number of principal components required to explain the stated fraction of activation variance. Fewer dimensions indicate stronger geometric compression, not necessarily better task information. |
| `activation_pca.participation_ratio` | Effective number of variance-bearing activation dimensions. |
| `component_readout_subspaces.mean_pairwise_overlap` | Normalized overlap of the four fitted component-belief readout subspaces: `0` means orthogonal directions and `1` means identical directions. Low overlap alone is not evidence of accurate component beliefs. |
| `coarse_over_identity_r2_advantage` | `aggregate_contrast R² - identity_deviation R²`. Positive and increasing values favor coarse machine health over named-component detail. |
| `permutation_invariant_r2_advantage` | `sorted_expected_condition R² - labeled_expected_condition R²`. Positive values favor unlabeled severity over fixed identities. |
| `behavior_reward_mean` | Mean reward of the fixed probe behavior policy, not the trained PPO policy. |
| `target_consistency_max_abs` | Numerical check that marginals used by probes agree with the exact joint Bayesian posterior. |

Linear decodability and PCA describe accessibility and geometry at the
pre-final-LayerNorm decision token. They do not prove causal policy use, and
they cannot rule out nonlinear information or information elsewhere in the
token sequence.

## Probe comparison

Values below are held-out R². `Δ` is final minus the untrained step-zero probe
within the same condition.

| target | global init | global final | global Δ | targeted init | targeted final | targeted Δ |
|---|---:|---:|---:|---:|---:|---:|
| Joint belief | .424 | .471 | +.048 | .192 | .139 | -.053 |
| Component contrast | .380 | .385 | +.005 | .460 | .243 | -.217 |
| Identity deviation | .239 | .128 | -.111 | .428 | .142 | -.286 |
| Aggregate contrast | .484 | .574 | +.090 | .549 | .527 | -.022 |
| Labeled expected condition | .498 | .448 | -.050 | .648 | .311 | -.337 |
| Sorted expected condition | .609 | .701 | +.091 | .653 | .569 | -.084 |
| Next-operate pass probability | .736 | .907 | +.172 | .839 | .905 | +.066 |
| Expected action reward | .736 | .907 | +.172 | .839 | .905 | +.066 |
| Broken-count distribution | .630 | .864 | +.234 | .678 | .671 | -.007 |
| Total correlation | .240 | .473 | +.232 | .187 | .145 | -.042 |

Summary diagnostics:

| diagnostic | global init → final | targeted init → final |
|---|---:|---:|
| Coarse-over-identity R² advantage | .246 → .447 | .121 → .385 |
| Activation CEV90 dimension | 6 → 2 | 10 → 1 |
| Activation participation ratio | 3.681 → 1.234 | 3.489 → 1.013 |
| Component-readout subspace overlap | .306 → .307 | .077 → .120 |

The global model increasingly favors permutation-invariant and
control-relevant information: aggregate health, next-operate success,
broken-count belief, and posterior dependence all become more decodable, while
identity deviation declines.

The targeted model moves in the **opposite direction from the prediction**.
Training substantially reduces joint, component, and identity-specific
decodability. Its expected immediate action reward remains highly decodable and
improves, but almost all activation variance collapses onto one principal
component: the first component explains 99.37% at the final checkpoint. The
most direct interpretation is that PPO learned a compressed control statistic,
approximately "how attractive is operating now?", rather than a linearly
resolved factored world model.

Absolute init values should not be interpreted as pretrained knowledge. Random
transformer features can make history-derived targets linearly decodable before
optimization, and the two action scopes have different input dimensions and
posterior distributions. The within-condition deltas are the more defensible
evidence.

## Reward performance

| condition | final sampled steps | final recorded 1,000-step episode return |
|---|---:|---:|
| Global | 5,015,952 | **Unavailable** |
| Targeted | 5,015,952 | **109.37 mean** over 240 completed episodes in the final Tune report; range `.48` to `212.28` |

The global run completed successfully, but its final Tune reporting window
contained zero completed 1,000-step episodes. Its final
`episode_return_mean`, minimum, and maximum are therefore recorded as `null`;
the checkpoint artifacts were not uploaded, so a frozen final-policy
reevaluation cannot be reconstructed from the compact result commit. As
context only, the separate seed-42 global run stopped near 1.02M steps and
recorded a mean episode return of **478.53**. That number must not be presented
as the missing global 5M final return.

For the targeted environment, simple 300-episode references were:

| policy | mean 1,000-step return |
|---|---:|
| Uniform random | -1,802.27 |
| Fixed probe behavior | -161.42 |
| Always operate | 39.06 |
| Trained PPO final reporting window | 109.37 |
| Exact-belief QMDP heuristic | 180.04 |
| Fully observed finite-horizon oracle | 769.63 |

The targeted PPO agent clearly learned beyond trivial behavior, reaching about
2.8 times the always-operate return. It nevertheless reached only about 61% of
the executable QMDP reference, so this run does not establish that belief
compression is a property of a near-optimal targeted policy. Incomplete policy
optimization remains a plausible contributor.

## Conclusions

1. **The global result supports coarse belief factoring.** Training improves
   aggregate and action-relevant decodability while reducing the cleanest
   identity-residual metric.
2. **Targeted action addressability did not preserve higher-resolution belief.**
   Against the prediction, nearly every Bayesian structure target declines,
   while immediate action reward remains strongly decodable.
3. **The targeted representation undergoes severe geometric compression.**
   One principal component explains 99.37% of final activation variance.
4. **The targeted agent learned, but was not demonstrably near-optimal.** Its
   reward exceeds random, fixed-behavior, and always-operate baselines, but
   trails the exact-belief QMDP reference.
5. **The causal factor is unresolved.** Targeting changes action semantics,
   cardinality, policy optimization difficulty, and the histories likely to be
   on-policy. A ten-action duplicated-global control is needed to isolate
   action-space size.

## Recommended follow-ups

- Repeat both 5M conditions across seeds.
- Save a final frozen-policy evaluation with action frequencies independently
  of Tune's last reporting window.
- Probe both matched fixed-behavior histories and each checkpoint's on-policy
  histories.
- Apply component-identity swap interventions and test whether targeted action
  logits swap correspondingly.
- Add a 10-action global-alias control to distinguish action cardinality from
  targeted transition semantics.
- Compare PPO directly with an exact-belief policy and record regret against
  the same executable reference.

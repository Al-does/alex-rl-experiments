# A/B pattern, embedding, and adjacent-checkpoint tests

## Main finding

The responses are dominated by token-label sensitivity, not the predicted
repetition/alternation effect. The preceding checkpoint is modestly more
sensitive to A/B randomization, but it also lacks the predicted response to
reward-state evidence. Increased final-policy confidence attenuates probability
changes; it does not explain away the missing evidence-aligned logit response.

These are supplementary tests of one training seed, not evidence that all
fine information is absent from hidden activations.

## 1. Matched AA/AB/BA/BB endings

For each of 26,085 eligible prefixes whose final two original observations
were A/B, fork the cache before those two observations and evaluate all four
endings. The earlier prefix and every action input stay fixed. Refilter the
four histories with the exact original environment model.

For Noop-minus-Tilt-X logit `L`, the primary contrast is
`(L_AB + L_BA - L_AA - L_BB) / 2`. This balances both label main effects.
The corresponding exact reward-state posterior contrast is +0.061045
(interval [0.061006, 0.061085]): alternation supplies more reward-state evidence.
An evidence-aligned preference response would have positive logit contrast.

| Mean logit contrast | Final | Previous |
| --- | ---: | ---: |
| Alternating minus repeated | -0.001300 | -0.001306 |
| 95% episode-bootstrap interval | [-0.001357, -0.001238] | [-0.001382, -0.001225] |
| Current A minus B, averaging previous labels | 0.328866 | 0.413229 |
| Previous A minus B, averaging current labels | 0.035340 | 0.043579 |

The pattern contrast is small and opposite to the predicted sign. It aligns
with the exact evidence in only 21.8% of final-checkpoint prefixes and 27.2%
of preceding-checkpoint prefixes. Its share of the sum of squared balanced
factorial contrasts is 0.00542% and 0.00567%, respectively; almost all of
that variation is in label main effects. This decomposition concerns these
four-ending interventions, not total neural representational variance.

The final mean Noop-probability pattern contrast is -0.00002560 (previous:
-0.00005003). No prefix has any greedy-action disagreement across its four
endings at either checkpoint. Action probabilities are not calibrated
reward-state estimates; these results do not prove that fine information is
absent or useless in every context.

## 2. Embedding interventions

The input embedding is a six-feature linear projection. In separate copies,
swap its A/B weight columns, or replace both columns by their mean. Leave the
C column, action columns, bias, and all later parameters unchanged. Recompute
every cache from reset.

| Mean action-distribution total variation from original | Final | Previous |
| --- | ---: | ---: |
| Independent A/B randomization | 0.001304 | 0.001391 |
| Global A/B input swap | 0.002219 | 0.002265 |
| A/B embedding-column swap | 0.002219 | 0.002265 |
| Mean A/B embedding columns | 0.001644 | 0.001939 |

Embedding-column swapping and global input swapping give identical logits
on the full evaluation. A global input swap preserves the exact reward-state
posterior, so the resulting probability changes cannot be attributed solely
to changed Bayesian reward-state evidence.

With mean A/B embeddings, randomized and original histories give identical
logits, and all four endings give identical logits. This is expected by
construction, not a localization of the original sensitivity to the input
layer alone. None of randomization, global swapping, or averaging embeddings
changes a greedy action at either checkpoint, including all 65,536 decisions
before warmup exclusion.

## 3. Adjacent checkpoint and confidence

| Quantity on the same histories | Final | Previous |
| --- | ---: | ---: |
| Randomization TV | 0.001304 | 0.001391 |
| RMS Noop-minus-Tilt-X logit change | 0.226139 | 0.279352 |
| Original policy entropy, nats | 0.077962 | 0.086439 |
| Mean maximum action probability | 0.986722 | 0.985070 |

The preceding checkpoint has 6.69% larger TV and 23.53% larger RMS logit
changes. The paired TV difference is +0.00008718 (interval
[0.00007822, 0.00009660]). The original greedy actions also match between
checkpoints on every scored decision.

As an output-level sensitivity diagnostic, applying the final checkpoint's
same logit perturbations to the preceding checkpoint's baseline logits gives
TV 0.001425, versus the actual final TV 0.001304 (9.3% greater). Conversely,
the earlier perturbations applied at final baseline logits give TV 0.001226,
versus actual preceding TV 0.001391. These are explicit logit recombinations,
not hidden-network interventions or a causal decomposition of training.
They support some attenuation from increased confidence.

Thus, the final update modestly reduces probability sensitivity, but neither
checkpoint exhibits the hypothesized reward-evidence-aligned pattern effect.
Residual label sensitivity plus confidence-dependent probability changes is
better supported than useful fine reward-state inference in the action readout.

## Verification and reproduction

- Six isolated tests cover embedding equivalence, source-weight preservation,
  mean embedding identity, balanced contrasts, exact suffix filtering/action
  timing, episode-bootstrap weighting, and global-swap reward-state invariance.
- Real-checkpoint smoke exercises all interventions at both checkpoints.
- Replaying the unmodified ending from each fork recovers its ordinary cached
  logits: maximum absolute error is 1.43e-6 across both checkpoints/embedding
  modes on the full evaluation.
- The original full-filter replay is checked against public environment belief
  diagnostics; the final model's original logits agree with the collector.

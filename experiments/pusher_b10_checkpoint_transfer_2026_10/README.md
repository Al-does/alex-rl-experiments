# Pusher-B b10 checkpoint transfer

This folder holds transfer tasks for pretrained Pusher-B b10 checkpoints.

- [`guess_or_pass_rllib/`](guess_or_pass_rllib/README.md) contains the RLlib
  PPO/SAC guess-or-pass study.
- [`guess_or_pass_jax/`](guess_or_pass_jax/README.md) contains the pure-JAX PPO
  port, which produced the campaign results.

See each subfolder's README for its methods, launch commands, and results.
